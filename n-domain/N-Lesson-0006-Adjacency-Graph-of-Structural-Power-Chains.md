# N‑Lesson‑0006 — Adjacency Graph of Structural Power Chains
Undirected Graph Structure over Iterated Concatenation

---

## 1. Purpose

This lesson defines the adjacency graph generated by structural power chains.
It repairs earlier issues of closure, directedness, and edge typing.

---

## 2. Vertex Set

For a fixed partition p ∈ N, define:

    Vₚ = { p^(⊗n) : n ∈ ℕ⁺ }

Each vertex is a structural power:

    p^(⊗1) = p
    p^(⊗2) = p ⊗ p
    p^(⊗3) = p ⊗ p ⊗ p
    …

This vertex set is **closed** under the successor operation n → n+1.

---

## 3. Edge Set (Undirected)

Define the undirected edges:

    Eₚ = { { p^(⊗n), p^(⊗(n+1)) } : n ∈ ℕ⁺ }

Each edge connects a power to its successor.

Properties:

• undirected  
• locally finite  
• every vertex has degree 2 except endpoints  
• graph is connected  

---

## 4. Graph Definition

The structural power chain graph is:

    Gₚ = (Vₚ, Eₚ)

This is an infinite undirected path.

---

## 5. Collapse Behavior

Collapse of a vertex:

    π(p^(⊗n)) = n · π(p)

Collapse of an edge:

    | π(p^(⊗(n+1))) − π(p^(⊗n)) |
    = | (n+1)·π(p) − n·π(p) |
    = π(p)

Thus collapse maps each edge to a constant step of size π(p).

---

## 6. Worked Example (Required)

Let:

    p = (b₁, b₂)
    deg(b₁) = 2
    deg(b₂) = 3

Then:

    π(p) = 5

Structural powers:

    p^(⊗1) = (b₁, b₂)
    p^(⊗2) = (b₁, b₂, b₁, b₂)
    p^(⊗3) = (b₁, b₂, b₁, b₂, b₁, b₂)

Graph vertices:

    Vₚ = { p^(⊗1), p^(⊗2), p^(⊗3), … }

Graph edges:

    { p^(⊗1), p^(⊗2) }
    { p^(⊗2), p^(⊗3) }
    …

Collapse values:

    π(p^(⊗1)) = 5
    π(p^(⊗2)) = 10
    π(p^(⊗3)) = 15

Thus collapse produces the numeric path:

    5 → 10 → 15 → …

with constant step 5.

---

## 7. Summary

This lesson establishes:

• vertex set Vₚ = { p^(⊗n) }  
• undirected successor edges  
• closed graph structure  
• collapse as a linear map on the path  
• worked example demonstrating structure  

This graph is required for structural distance (Lesson 0007).
