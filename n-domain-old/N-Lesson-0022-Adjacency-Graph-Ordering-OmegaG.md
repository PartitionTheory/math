# N‑Lesson‑22 — Adjacency Graph Ordering (ΩG)

Adjacency graph ordering ΩG is the first operator that defines successor relations at the graph 
level rather than the partition level. It arises directly from adjacency graph density (ΔG) and 
completes the core triad of Phoenix Epoch‑9 adjacency calculus:

- Gₛ — adjacency graph formation,
- ΔG — adjacency graph density,
- ΩG — adjacency graph ordering.

ΩG is not numeric ordering, not topological sorting, and not graph traversal. It is structural 
graph ordering, built entirely from:
- Δ (Partition Density),
- Ω (Structural Ordering),
- ×ₛ (Structural Multiplication),
- !ₛ (Structural Factorial),
- Πₛ and Cₛ (Structural Combinatorial Operators),
- Rₛ (Synthetic Recursion),
- Aₛ (Adjacency Recursion),
- Tₛ (Structural Recursion Trees),
- Gₛ (Adjacency Graph Operator),
- ΔG (Adjacency Graph Density).

ΩG defines structural successor relations between adjacency graphs.

## 2. Definition of Adjacency Graph Ordering (ΩG)

Let N be a structural domain, and let p be a partition index.

Definition:

ΩG(p) = Gₛ(Ω(p))

Where:
- Ω(p) is the structural successor of p,
- Gₛ(Ω(p)) is the adjacency graph generated from that successor,
- ΩG(p) is the next adjacency graph in the structural ordering chain.

In words:
ΩG is the graph‑level successor operator: the next adjacency graph generated by the structural 
successor of p.

---

## 3. Properties of ΩG

### 3.1 Non‑Arithmetic
ΩG does not compute numeric ordering.  
It computes structural graph ordering.

### 3.2 Ordering‑Driven
Ω determines the successor relation.

### 3.3 Graph‑Level
Gₛ determines the graph structure at each successor step.

### 3.4 Density‑Aware
ΔG determines the load of each graph in the ordering chain.

### 3.5 Domain‑Dependent
ΩG depends entirely on the N‑domain.

---

## 4. Interpretation

ΩG answers:

“What is the next adjacency graph in the structural ordering chain generated from partition p?”

This is the structural analogue of graph successor relations.

---

## 5. Conceptual Example

If Δ(p) = 3:

ΩG(p) = Gₛ(Ω(p))  
ΩG(Ω(p)) = Gₛ(Ω²(p))  
ΩG(Ω²(p)) = Gₛ(Ω³(p))

This represents:
- graph‑level successor relations,
- ordering‑driven graph progression,
- density‑driven graph load variation.

ΩG is structural graph ordering, not topological sorting.
