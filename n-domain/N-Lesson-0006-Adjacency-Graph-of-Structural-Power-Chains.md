# N‑Lesson‑0006 — Adjacency Graph of Structural Power Chains
One-Sided Infinite Path over Iterated Concatenation

---

## 1. Purpose

This lesson constructs the adjacency graph generated by structural power
chains. It uses only the powers of a fixed partition p and successor edges
between consecutive powers.

---

## 2. Vertex Set

For a fixed p ∈ N⁺, define:

    Vₚ = { p^(⊗n) : n ∈ ℕ⁺ }

Each vertex is a structural power:

    p^(⊗1) = p
    p^(⊗2) = p ⊗ p
    p^(⊗3) = p ⊗ p ⊗ p
    …

The vertex set is closed under successor motion n → n+1.

---

## 3. Edge Set (Undirected)

Define the undirected edges:

    Eₚ = { { p^(⊗n), p^(⊗(n+1)) } : n ∈ ℕ⁺ }

Each edge connects a power to its successor.

Thus the graph is:

    Gₚ = (Vₚ, Eₚ)

This is a one-sided infinite path.

---

## 4. Vertex Degrees (Corrected)

Because indexing begins at n = 1:

• the initial vertex p^(⊗1) = p has degree 1  
• every vertex p^(⊗n) with n ≥ 2 has degree 2  

There is **one endpoint**, not two.

---

## 5. Collapse Behavior

Collapse of a vertex:

    π(p^(⊗n)) = n · π(p)

Collapse difference between consecutive vertices:

    π(p^(⊗(n+1))) − π(p^(⊗n)) = π(p)

Thus collapse maps each edge to a constant step of size π(p).

---

## 6. Worked Example

Let:

    p = (b₁, b₂)
    deg(b₁) = 2
    deg(b₂) = 3

Then:

    π(p) = 5

Structural powers:

    p^(⊗1) = (b₁, b₂)
    p^(⊗2) = (b₁, b₂, b₁, b₂)
    p^(⊗3) = (b₁, b₂, b₁, b₂, b₁, b₂)

Graph vertices:

    Vₚ = { p^(⊗1), p^(⊗2), p^(⊗3), … }

Graph edges:

    { p^(⊗1), p^(⊗2) }
    { p^(⊗2), p^(⊗3) }
    …

Collapse values:

    π(p^(⊗1)) = 5
    π(p^(⊗2)) = 10
    π(p^(⊗3)) = 15

Thus collapse produces the numeric path:

    5 → 10 → 15 → …

with constant step 5.

---

This lesson establishes:

• vertex set Vₚ = { p^(⊗n) }  
• undirected successor edges  
• one-sided infinite path structure  
• corrected vertex-degree statement  
• collapse step equality  
• worked example demonstrating structure  

This prepares the foundation for structural distance (Lesson 0007).
