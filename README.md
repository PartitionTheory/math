## Architectural Spine

The N‑Domain is built as a typed chain of mathematical constructions:

1. **Structured Partitions (P)**  
   Objects are finite sequences of positive integers.  
   Algebraic operations: concatenation `⊗` and collapse `π`.

2. **Typed Adjacency (E₁, E₂, E_adj)**  
   - `E₁`: unit coordinate changes  
   - `E₂`: concatenation edges  
   - `E_adj`: full typed graph structure  
   These define the discrete geometry of the domain.

3. **Positional Hilbert Embedding ψ : P → ℓ²(ℕ⁺ × ℕ⁺)**  
   Injective one‑hot positional encoding enabling analytic tools without imposing manifold structure.

4. **Ambient Calculus (Φ, ∇Φ, J_F^Φ, H_F^Φ)**  
   Derivatives, Jacobians, and Hessians are defined only through ambient extensions Φ.  
   Structural moves are discrete; finite differences remain primary.

5. **Graph Operators (d₁, d_adj, Laplacians)**  
   Typed distances and discrete Laplacians define the combinatorial geometry.

6. **Typed Correspondences (T, T_f^a, T_f^{<,a})**  
   Set‑valued update rules governing structural flows.  
   Deterministic selections (e.g., shortlex) are conventions, not intrinsic.

7. **Stability Theory**  
   Weak and strong fixed points, strict descent, finite‑sublevel convergence, ε‑descent termination.

8. **Landscapes and Epochs**  
   Communication heights, barrier states, plateau complexes, basins, and epoch transitions across λ.

Each arrow in this chain is **typed**, ensuring mathematical discipline and preserving the original ABR insight
while making the theory fully defensible.
