## Overview

This repository contains the launch edition of:

**The Partition Machine: A Beginner Lesson and Formal Statement**

The work introduces the **PMachine**, also called the **Partition Machine**, as an entry point into Partition Theory.

The document develops the PMachine through a human-readable lesson sequence before giving a formal mathematical statement and theorem-level formulation.

Topics include:

- left-bounded partition tape;
- symbolic partition scissors;
- finite tape cuts and unary decomposition;
- partition input and grouped structure;
- operational memory;
- clocked product state;
- N and N−1 presentations;
- colour-coded pattern–clock–information displays;
- teacher/grid-paper aids;
- clock-to-state recovery;
- the visual tape paradox;
- formal PMachine definition;
- theorem-level formulation.

---

## Core Statement

The PMachine is presented as a finite ordered product-memory mechanism in which:

- the partition input determines the operational memory size;
- the product of the input groups determines the clock;
- ordered block structure determines internal numerical state;
- displayed clock values can be restored and decoded by subtraction and remainder passage;
- teaching stacks are visual aids, not computational requirements;
- N and N−1 are distinct presentations of the same instructional machine context;
- visual sameness of tape notation does not alone determine machine state.
