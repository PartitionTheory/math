Add N‑Domain structural mathematics (Lessons 1–10)

This commit introduces the complete N‑Domain structural mathematics set,
consisting of ten lessons that define the foundational domain, boundary,
operator, cost, gradient, and coherence structures required for ABR‑Rebirth.

These documents are *Phoenix‑derived* but not Phoenix synthetic mathematics.
Phoenix deals with agency, totality, synthetic time, and multi‑domain recursion.
The N‑Domain lessons instead define the structural, reversible, cost‑bounded
mathematics needed for ABR runtime design.

This commit formally separates:

• Phoenix synthetic mathematics  → (phoenix/)
• Partition Theory               → (partition-theory/)
• N‑Domain structural mathematics → (n-domain/)

The N‑Domain now serves as the public mathematical spine for the upcoming
ABR‑Rebirth repository, providing a clean conceptual layer distinct from
Phoenix’s synthetic lineage.
