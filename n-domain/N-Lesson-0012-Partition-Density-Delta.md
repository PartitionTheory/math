mathematical engine. Δ provides the first structural measure of relational load inside an N‑domain.

## 1. Motivation

interprets {2,3} as 6 permutations; structural mathematics interprets it as relational load.

## 2. Definition of Partition Density (Δ)
Let N be a structural domain and p a partition index.

Δ(p) = the number of structural relations that partition p participates in within the N‑domain.

Δ counts relations, not arithmetic magnitude.

- Non‑Arithmetic: Δ does not depend on numeric value.
- Positional: Δ depends on structural position.
- Relational: Δ measures adjacency, window membership, operator influence.
- Domain‑Dependent: Δ changes with the N‑domain.
